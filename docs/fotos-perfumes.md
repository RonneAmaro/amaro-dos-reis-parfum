# Fotos dos perfumes — Amaro dos Reis Parfum

Este guia ajuda a manter um padrao visual premium para as fotos dos perfumes no catalogo.

## Como tirar as fotos

- Use fundo neutro, de preferencia preto, cinza, branco ou madeira discreta.
- Fotografe com boa luz natural, perto de uma janela, evitando sol direto forte.
- Limpe o frasco antes da foto para remover marcas de dedo e poeira.
- Evite reflexos fortes no vidro e no rotulo.
- Tire uma foto frontal do frasco, bem alinhada e com espaco ao redor.
- Tire uma foto com cenario, usando elementos que combinem com a fragrancia.
- Tire uma foto da caixa ou embalagem quando existir.
- Mantenha sempre o mesmo padrao visual para o catalogo parecer profissional.

## Campos do painel

- **Imagem principal**: foto real do frasco, usada como imagem principal no catalogo.
- **Imagem conceitual**: imagem de cenario, ingredientes ou notas olfativas, podendo ser criada por IA.
- **Galeria**: outras fotos do produto, detalhes, caixa, composicao ou ambiente.

## Como usar agora

Na galeria, informe uma URL por linha.
