# Deploy Vercel — Amaro dos Reis Parfum

## Passos

1. Acessar Vercel.
2. Importar o repositorio GitHub.
3. Configurar a variavel `NEXT_PUBLIC_WHATSAPP_NUMBER`.
4. Fazer o deploy.
5. Conferir o site online.

## Comandos locais

```bash
npm.cmd install
npm.cmd run dev -- -p 3001
npm.cmd run build
```
